# The Movers — plain-language README

## What this is
An idea for a team of AI helpers that move things (such as files or projects) exactly as they are and set them up neatly in their new place. What makes them different:
- A job only counts as finished when the same person who asked for it approves it.
- Once approved, the helpers drop the job from memory.

## Who it's for
Anyone who wants moves and setups done carefully, with a clear sign-off.
